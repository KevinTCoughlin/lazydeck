# LazyDeck governance

LazyDeck is currently maintained by its repository owner. Issues and pull
requests are welcome from everyone; the maintainer makes final decisions on
scope, releases, compatibility, and security fixes.

## Contributions

Contributors should follow [CONTRIBUTING.md](CONTRIBUTING.md), keep changes
focused, and include tests or explain hardware/editor limitations in the pull
request. Maintainers review changes for correctness, user impact, security,
and long-term maintenance cost.

## Decisions and releases

Technical discussion happens in GitHub issues and pull requests so decisions
remain public and searchable. Releases are tagged from `main` after CI passes;
the release workflow produces signed provenance, SBOMs, checksums, archives,
and Debian packages.

## Changes to this document

The maintainer may evolve this lightweight model as the contributor community
grows. Significant changes will be proposed and discussed in a public issue.
